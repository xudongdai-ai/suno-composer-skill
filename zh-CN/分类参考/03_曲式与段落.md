# 曲式与段落

**本类解决：一首音乐怎样开始、变化与结束。**

日常只上传完整作曲助手；本文件供按主题查阅。

<a id="ref-form-selection-guide"></a>

## 常见段落与结构选择

曲式回答的是：“先出现什么、哪里发生对比、高潮在哪里、怎样结束”。它与“什么流派”和“用什么乐器”分开选择。

### 歌曲段落名称对照

| 中文 | 常见标签 | 这段负责什么 |
|---|---|---|
| 前奏 | Intro | 建立音色与律动，让听者进入场景 |
| 主歌 | Verse | 讲故事、给信息，通常留出空间 |
| 预副歌 | Pre-Chorus | 从主歌走向副歌，逐渐抬升期待 |
| 副歌 | Chorus | 呈现中心主题与最容易记住的句子 |
| 副歌后段 | Post-Chorus | 延续一个短 Hook 或器乐记忆点，可省略 |
| 间奏 | Instrumental Break | 让乐器回应主题，给人声休息 |
| 桥段 | Bridge | 后半段出现新视角或明显对比 |
| 尾奏 | Outro | 收回主题、渐弱或明确结束 |

### 不同用途可以选什么结构

| 用途 | 易理解的起点 | 关键区别 |
|---|---|---|
| 常规流行歌曲 | 前奏—主歌—预副歌—副歌—主歌—副歌—桥段—最后副歌—尾奏 | 副歌重复，但第二主歌有新信息 |
| 简短歌曲或短片片段 | 前奏—主歌—副歌—尾奏 | 减少铺垫，较快到达主题 |
| 民谣叙事 | 主歌—主歌—副歌—主歌—副歌 | 以故事推进，不必强加预副歌 |
| 电子舞曲 | 引入—律动—减法段—渐强—Drop—收束 | 能量与低频变化比歌词叙事更关键 |
| 纯器乐小品 | A—B—A′ | A 是主题，B 是对比，A′ 是有变化的回归 |
| 电影配乐 | 建立—发展—转折—高潮—余韵 | 跟随画面情绪与时间安排 |
| 游戏背景循环 | 稀疏 A—增强 B—回到 A—连接点 | 结尾能否接回开头需要音频检查 |

小节是组织节拍的单位，建议小节数用于策划，不是生成结果的保证。在 4/4、以四分音符为 BPM 单位时，一小节秒数约为 `4 × 60 / BPM`。下面的曲式库提供更深入的 17 种原型。

## 17 种曲式原型

> 所有小节数都是用于组织创作的建议。Suno 的自然语言生成不保证精确小节与时长；生成后需要试听与人工剪辑。

### 17 种可选结构原型

| 类型 | 结构与建议小节 | 关键发展逻辑 |
|---|---|---|
| 01 流行单曲 | Intro 4–8 / V1 8–16 / Pre 8 / C 8–16 / V2 8 / C 16 / Bridge 8 / Final C 16 | Verse 低密度、Pre 属功能准备、Chorus 音区与和声节奏扩张 |
| 02 中文抒情 | Piano Intro 4 / V1 16 / V2 8 / Pre 8 / Chorus 16 / Bridge 8 / Final 16 | 主旋律跨句连贯，终曲可大幅配器，但避免失控 |
| 03 EDM | DJ intro 16 / Groove 16 / Break 16 / Build 8 / Drop 32 / Break 16 / Drop 32 / Outro 16 | 用低频、滤波、律动切换控制能量 |
| 04 House | Intro 16 / Bass Groove 16 / Vocal Hook 16 / Breakdown 16 / Drop 32 / Outro 16 | 适合混音的 8/16 小节渐入渐出 |
| 05 DnB | Atmos 16 / Lift 16 / Drop 32 / Bridge 16 / Second Drop 32 / Outro 16 | 快速 breakbeat 与 sub 交互，为 bass 留空间 |
| 06 Hip-hop | Intro 4–8 / Verse 16 / Hook 8 / Verse 16 / Hook 8 / Outro 4 | 韵律与停顿重于和弦复杂度 |
| 07 Neo-soul | Intro 4 / Verse 16 / Hook 8 / Instrumental 8 / Verse 8 / Reharm Hook 8 | 每次 Hook 可用变化低音或替代和弦 |
| 08 Jazz AABA | A 8 / A 8 / B 8 / A 8 + Solos | A 建立动机、桥段转调或跨调性张力 |
| 09 Jazz blues | 12-bar blues head / solos / head | I7–IV7–V7 及替代需与乐队口袋协同 |
| 10 赋格 | Subject / Answer / Counter-subject / Episodes / Middle entries / Stretto / Final entry | 主题可辨性高于织体填充，答题与对题的调性关系需审校 |
| 11 奏鸣曲式 | Exposition / Development / Recapitulation / Coda | 主题与调性关系是关键，不等同“ABA” |
| 12 变奏曲 | Theme 8–16 / Variations x3–6 / Reprise | 保留动机/低音/和声骨架，改变纹理、节奏、配器 |
| 13 A–B–A′ | A 16 / B 16 / A′ 16 / Coda 8 | B 应改变调性、织体或节奏；再现具有意义的变化 |
| 14 Rondo | A–B–A–C–A | A 不变核心动机，B/C 强烈对比 |
| 15 后摇长弧 | Drone intro / Repeated figure / Counterline / Layer build / Peak / Dissolve | 延迟进入的主旋律与动态增强是高潮依据 |
| 16 电影提示段 | Establish / Motif / Development / Crisis / Peak / Aftermath | 关注画面时间码与情绪转折，避免从头到尾满编制 |
| 17 游戏循环 | Sparse Loop A / Intensified Loop B / Return / Seam | 结尾与开头拍点/和声/混响尾需可无缝拼接（音频检验） |

### 作曲级的变化技巧
- **Motivic development**：倒影、逆行、节奏扩张/紧缩、顺序模进、改变和声支点；纯文字描述不保证算法级严格实现。
- **Register architecture**：A 段中音区、B 段高音域扩展；副歌前最好预留声学空间。
- **Harmonic rhythm**：Verse 两小节一和弦，Pre 一小节一个和弦，Chorus 在关键长音处延长主和弦。
- **Textural subtraction**：高潮前短时抽走低频或鼓组，增强返回的冲击。
- **Thematic recapitulation**：最后不是“再来一次 A”，而是 A 在更高音区、变宽和声或改变配器后的意义再现。
- **Classical cadence**：half cadence / authentic cadence / deceptive cadence 用于结构分界；需注意实际声部导向。

### 时长估算（仅策划）
单个 4/4 小节时长（秒）≈ `4 × 60 / BPM`。例如 120 BPM 的 16 小节约 32 秒。实际 rubato、拍号变化、休止与生成时长会偏离。
