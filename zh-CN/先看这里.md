# 先看这里：作曲助手怎么用

这套资料帮你把一个主题，整理成歌词、音乐风格和编曲方案。GPT 负责写方案，你把结果复制到 Suno 生成音乐。

英文名：**Songwriting Assistant**。

简介与分享文案见 [04_助手简介.md](04_助手简介.md)。

## 第一步｜只上传这个文件

把 **[01-作曲助手.md](01-作曲助手.md)** 拖入 GPT 对话。日常使用只上传这一份，它已经包含全部分类资料。

## 第二步｜告诉 GPT 你想做什么

上传后发送，例如：

```text
请按上传的 作曲助手工作。
写一首中文歌，主题是夜里开车回家，温暖复古，副歌容易记住。
人声、速度和曲式请帮我建议。
给完整歌词、可复制的英文 Styles、Exclude 和中文编曲表。
```

也可以只说“只写歌词”“我的原词不改，只配曲”“只改副歌”“做纯音乐”。不懂流派名称也能用。想写得更具体，打开 [02_填写你的创作需求.md](02_填写你的创作需求.md)；想照着例子提问，打开 [03_直接复制的提问示例.md](03_直接复制的提问示例.md)。

## 第三步｜把结果分别复制到 Suno

| GPT 输出的标题 | 你怎么使用 |
|---|---|
| 风格提示词 / Styles | 精简版和扩展版选一个，复制对应代码块到 Styles |
| 完整歌词 / Lyrics | 只复制歌词代码块到 Lyrics |
| 排除项 / Exclude | 复制到当前界面的 Exclude（若提供） |
| 纯音乐设置 | 开启 Instrumental，歌词栏留空 |
| 曲式与编曲表 | 看段落怎么安排、乐器怎么进出，留作制作计划 |
| 生成后修改建议 | 听过结果后再用；一次先解决一个问题 |

## 你不用先学会这些术语

| 词 | 白话意思 |
|---|---|
| 风格 | 音乐的类型和听感，例如华语流行、City Pop、爵士 |
| 曲式 | 段落顺序，例如前奏—主歌—副歌—桥段—尾奏 |
| Hook | 最容易记住的一句词或一小段旋律 |
| 和声 | 旋律下面的和弦与色彩 |
| 配器 | 哪些乐器出现、各自负责什么 |
| BPM | 每分钟的拍数，通常用来描述速度 |
