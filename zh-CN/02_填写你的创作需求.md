# 填写你的创作需求

先填下面的五项就能开始。不懂的地方写“请帮我建议”，不用学习全部乐理。

## 简单版：适合第一次使用

复制这个框里的内容，填好以后发给已经读取作曲助手文件的 GPT。

```text
请按上传的 作曲助手工作。

我想做：完整歌曲 / 只写歌词 / 已有歌词配曲 / 改词 / 纯音乐
主题或画面：
希望听起来怎样：
歌词语言、人声或纯音乐：
不要的元素：

其他参数请帮我建议。按本次任务直接给可用成果。
```

“希望听起来怎样”可以写流派名字，也可以写“温暖复古、鼓点轻、主唱贴近耳边”。

## 详细版：有明确想法时再用

### A｜主题与歌词

```text
主题与故事：
叙述者 / 对谁说话：
歌词语言：
必须保留的句子或关键词：
押韵、行数或用词要求：
```

### B｜风格与人声

```text
主风格：
辅风格及用途（可省略）：
人声或纯音乐：
演唱质感：
```

### C｜曲式与情绪

```text
目标时长（近似）：
段落顺序（可让 GPT 建议）：
情绪怎样变化：
高潮希望出现在什么地方：
```

### D｜和声、乐器与声音

```text
速度 BPM、拍号、调性（可让 GPT 建议）：
主要乐器：
其他乐器：
声音空间 / 制作感觉：
不要的元素：
```

### E｜已有作品与交付范围

```text
已有歌词或 Styles：
哪些内容原样保留：
哪些内容允许修改：
本次只需要哪些输出：
Style 字符预算（可省略）：
```

不需要把所有空项发给 GPT。只留下你关心的类别，或用一句话描述也可以。
