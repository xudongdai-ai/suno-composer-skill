# Songwriting Assistant — Start Here

This assistant helps you turn a theme, scene or existing lyric into original lyrics, a musical direction and an arrangement plan. GPT prepares the text; you use the relevant fields in Suno to generate and listen to the music.

## Step 1 — Upload one file

Upload **[01_Upload_to_GPT_Songwriting_Assistant.md](01_Upload_to_GPT_Songwriting_Assistant.md)** to a conversation that supports Markdown attachments. That single file already includes the complete reference library.

## Step 2 — Describe what you want

```text
Use the uploaded Songwriting Assistant.
Write an English song about driving home at night and learning to start again.
Keep it warm and gently retro, with an easy-to-remember chorus.
Suggest the voice, tempo and structure.
Give me complete lyrics, compact and extended Suno Styles, Exclude,
and a clear arrangement table.
```

You can also ask for lyrics only, a new style for unchanged lyrics, a chorus rewrite or an instrumental. You do not need to know music theory. Use [02_Creative_Brief_Template.md](02_Creative_Brief_Template.md) for a more detailed brief or copy a request from [03_Ready_to_Use_Requests.md](03_Ready_to_Use_Requests.md).

## Step 3 — Copy each result to the right place

| GPT output | What to do with it |
|---|---|
| Compact or extended Styles | Choose one version and copy its text block to Styles / Style of Music |
| Complete lyrics | Copy only the lyric block to Lyrics |
| Exclude | Copy to the Exclude option if your current interface provides it |
| Instrumental instructions | Enable Instrumental and leave Lyrics empty |
| Form and arrangement table | Keep as a production plan; do not put it in Lyrics |
| Revision suggestions | Use after listening; address one problem at a time |

## Plain-language glossary

| Term | Meaning |
|---|---|
| Genre / style | The musical identity, such as city pop, jazz or indie pop |
| Form / structure | The order and function of sections |
| Hook | A short lyric or musical idea that is easy to remember |
| Harmony | The chords and their color underneath the melody |
| Arrangement / orchestration | Which instruments play, what they do and when they enter |
| BPM | Beats per minute, used to describe tempo |

To share it, send the English ZIP. The recipient reads 00 and uploads 01. No installation or code execution is required. Upload again in a new conversation. If the attachment cannot be read, attach it again rather than assuming it has loaded.

The package creates text plans, not audio. Tempo, key, chords, section lengths and total duration are creative targets; listen to the generated result to check them.
